## 主要代码怎么理解

- HTML 用 `header`、`main`、`section` 和 `footer` 组织页面。导航的 `href="#work"` 会跳到 `id="work"` 的项目区域。
- CSS 用变量统一颜色，用 Grid 排列首屏与项目图文，偶数项目把封面放在右侧；`@media(max-width:760px)` 将手机内容变成单列，并启用折叠菜单。生活照通过固定比例的显示区域取景，概念 SVG 图形没有外部依赖。`:hover` 和 `:focus-within` 分别响应鼠标与键盘聚焦，CSS 过渡及关键帧控制封面动效；减少动效偏好会关闭动画。
- JavaScript 给按钮绑定点击事件。手机菜单同步 `aria-expanded` 状态；封面与文字按钮均带 `data-project`，从同一个 `projects` 对象取出内容，填入原生 `dialog`；复制邮箱使用 Clipboard API，并在失败时给出真实提示。
- 关于我三个标签与标题关键词共用 `showAbout`。它切换面板的 `hidden`、标签的 `aria-selected` 和照片状态；每次只有一个标签可通过 Tab 键进入，左右方向键及 Home/End 在标签间移动。打印始终展示概览内容。字体只覆盖当前标题与边注，来源和许可见 `assets/fonts/README.md`。
- IntersectionObserver 观察标记了 `data-reveal` 的区块进入视口，在出现时加上 `is-visible` 类，再由 CSS 产生淡入效果。选择减少动效时保留内容可见并关闭淡入。
- 主要交互可以在浏览器开发者工具中观察。理解以上代码仍需本人阅读与实践，不能把这份说明当成已经掌握的证明。

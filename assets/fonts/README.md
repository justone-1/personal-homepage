# 关于我标题字体

`MaShanZheng-About.woff2` 来自 Google Fonts 收录的 Ma Shan Zheng Regular，按本站标题和照片边注使用的文字制作 WOFF2 字形子集（约 5.6 KB）。字体设计及原始版权归原项目作者；子集仅供页面使用，未声称本站原创字体。

- 字体来源：https://github.com/google/fonts/tree/main/ofl/mashanzheng
- 上游项目：https://github.com/googlefonts/mashanzheng
- 随附原始许可：`MaShanZheng-OFL.txt`，SIL Open Font License 1.1。

标题和边注使用手写字体；正文采用常见无衬线字体。字形子集只覆盖当前使用的文字，今后新增手写文字时需补充子集或采用回退字体。此文件与许可应随字体一起保留。
